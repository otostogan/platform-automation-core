# Platform Automation Core v0.21.2

The metrics exporter writes its numbers in full.

Release assets:

- `otostogan-platform-0.21.2.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.21.2-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- Fix the exporter rounding every value to six significant digits. A Unix
  timestamp lost its last four digits — up to 2.7 hours — so "Platform
  metrics stopped" fired while metrics were arriving, and the age of the
  newest dump, of the proven restore and of the deploy were wrong by the
  same amount, on the dashboard and in the alert rules. Present since
  v0.20.0.

Upgrade: pin `v0.21.2`, converge. A false "Platform metrics stopped" alert
resolves by itself within a few minutes.

# Platform Automation Core v0.3.1

The core repository is now public, so consuming a release no longer requires
a credential.

Release assets:

- `otostogan-platform-0.3.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.3.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `platform_core_token` and the bundle action's `github-token` are optional.
  The workflow-provided token reads the public core, so an application
  repository no longer has to hold a credential just to fetch the runtime;
  supply one only when consuming a private fork.
- Repository and release boundary scans no longer fail when no private marker
  list is supplied. The generic patterns run regardless, and fork pull
  requests — which are never given secrets — no longer fail on the absence of
  a list rather than on their own content.
- Build metadata (`*.egg-info`) is excluded from the collection artifact.

Behavior of the `platform/v1` contract, the server CLI, nginx activation,
rollback, boot secret recovery, and the SOPS recipient policy is unchanged.

# Platform Automation Core v0.2.0

This release hardens the proprietary core boundary and makes subsequent stable
releases version-driven.

Release assets:

- `otostogan-platform-0.2.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.2.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Highlights:

- removes company, lab, controller-local, and migration-source values from the
  current core tree and release artifacts;
- rejects non-allowlisted domains, public addresses, Tailscale identities,
  credentials, private inventory, and runtime-supplied markers;
- makes repository and release scans fail closed when their private marker list
  is missing;
- derives release artifacts and notes from the validated semantic tag;
- retains the `platform/v1` contracts, collection roles and playbooks, server
  CLI, nginx activation transaction, rollback, and reboot recovery behavior.

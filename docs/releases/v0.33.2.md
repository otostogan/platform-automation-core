# Platform Automation Core v0.33.2

A deployment waits for the nginx fragment lock instead of failing on the
reconcile timer's second.

Release assets:

- `otostogan-platform-0.33.2.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.33.2-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `platform deploy` waits up to a minute for the nginx fragment lock before
  refusing with `another nginx fragment transaction is in progress`. The
  reconcile timer takes that lock for about a second every ten seconds and
  a deployment landing in that second was refused for no reason; the timer
  itself still skips a tick when a deployment holds the lock.

- Sizes read as `809 KB` or `1.2 MB` in the console's backup list and
  restore choice.

Upgrade: pin `v0.33.2`, converge. Nothing changes in applications.

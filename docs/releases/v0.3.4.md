# Platform Automation Core v0.3.4

Makes a second convergence report no change, which is what the acceptance
sequence asks operators to confirm.

Release assets:

- `otostogan-platform-0.3.4.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.3.4-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- Three tasks refreshed the APT package index on their own, without installing
  anything, and reported `changed` once the cache aged past
  `cache_valid_time`. Any convergence run more than an hour after the previous
  one therefore reported a change that was not one — and the runbook asks
  operators to accept a host by confirming the opposite. Refreshing an index
  is a precondition rather than host state, so those tasks no longer report a
  change; package installs still report their own.
- A test walks every role and fails if a task refreshes the cache without
  installing and without suppressing the change, so the signal cannot rot
  again.

No behavior changes on the host.

Changes:

- `platform backups` reports `offsite_only`: dumps retention removed from
  the host that the bucket still keeps. `platform verify-backup
  --from-offsite` fetches such a dump with the operator's reader
  credentials on standard input and then proves it. The console's
  "Database: restore" lists these dumps as "in the bucket only", asks for
  the reader credentials file, fetches and proves the dump, and continues
  with the ordinary restore; the key never lands on the host.

# Platform Automation Core v0.31.0

An application may declare that it has no database.

Release assets:

- `otostogan-platform-0.31.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.31.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `database.mode: none` for a static site or an application without a
  database. The block then carries only `mode` and `backup_enabled: false`;
  `postgres_major`, `backup`, `resources` and the top-level
  `restore_validation` are refused. `platform secrets push` neither requires
  nor drops `DATABASE_URL`, no backup timer is reconciled, and
  `platform backup`, `restore` and `verify-backup` refuse with the reason.
  `platform new app` offers the mode and writes the manifest for it. A
  placeholder `DATABASE_URL` and a `restore_validation` nobody can run are
  no longer needed in such a manifest.

- `platform new app` writes a Compose file without the `db` network when
  the database is external or absent, and lowercases the ghcr.io owner it
  derives from the git remote or takes from the wizard.

Upgrade: pin `v0.31.0`, converge. A host on an older core refuses a
manifest with `mode: none`, so converge before deploying one. Existing
applications change nothing.

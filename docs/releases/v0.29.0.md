# Platform Automation Core v0.29.0

Basic auth on chosen paths of a domain.

Release assets:

- `otostogan-platform-0.29.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.29.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `domains[].auth.paths` puts only the listed paths of a domain behind the
  basic auth, each with everything under it; the rest of the host stays
  open. Paths are the external ones, with the application's prefix. The
  hash file is `htpasswd/<host>_paths`, read only by the locations the
  platform renders into the host's vhost fragment. A path equal to or under
  the guarded metrics path is refused, as is a host name too long to carry the
  suffix. Without `paths` nothing changes.

Upgrade: pin `v0.29.0`, converge. Then `platform update` in each
application: its deploy workflow is pinned to the release, and the runtime
of v0.28.0 refuses the new field. An application then adds `paths` to the
`auth` block of a domain and tags a new version.

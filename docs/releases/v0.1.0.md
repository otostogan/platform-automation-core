# Platform Automation Core v0.1.0

The first private release separates reusable automation IP from company and
application data while preserving the accepted platform behavior.

Release assets:

- `otostogan-platform-0.1.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.1.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

The release keeps `platform/v1`, bundle v1, release v1, the
`platform deploy|status|rollback` interface, nginx/docker-gen/ACME activation,
reboot recovery, and existing `/opt/platform`, `/var/lib/platform`, and
`/run/platform` boundaries. It does not migrate any real inventory, domain,
address, credential, key, age recipient, acceptance log, or customer value.

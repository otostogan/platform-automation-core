# Platform Automation Core v0.26.1

The standard dashboard's domain-filtered panels work again.

Release assets:

- `otostogan-platform-0.26.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.26.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- Fix every domain-filtered panel of the standard dashboard answering
  "parse error" — requests, 5xx share, response time, responses by class and
  the three path tables. Since v0.23.0 "All" domains expands to the
  application's own domains, written with escaped dots, and LogQL does not
  accept `\.` inside a double-quoted string. The filter is now a raw string.
- The build and release workflow templates write their tag pattern without
  quotes, so an application's formatter has nothing to rewrite and
  `platform doctor` no longer reports the file behind its template.

Upgrade: pin `v0.26.1`, converge; the convergence restarts Grafana once.
Then `platform update` in each application.

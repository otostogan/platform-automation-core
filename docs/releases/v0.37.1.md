# v0.37.1

Patch release: `platform update --host` works from the command line.

## Fixed

- 0.37.0 documented `platform update --host <environment>=<host>` and
  handled it in the console, but the `platform` binary never registered the
  option and refused it as an unrecognised argument. The option is now
  accepted, may be repeated, and is covered by a test that runs the real
  command line.

## Upgrade

- Workstation: reinstall the console wheel from this release.
- Hosts: no runtime change; converging with the 0.37.1 collection is
  optional.

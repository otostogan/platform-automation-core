# Platform Automation Core v0.31.1

The console waits for the Tailscale SSH browser check, and the application
pre-commit hook lets `.env.example` through.

Release assets:

- `otostogan-platform-0.31.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.31.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- The console no longer crashes with a `subprocess.TimeoutExpired` traceback
  when the tailnet's ssh policy has `action: check`. Every remote call that
  captures ssh output watches stderr: when Tailscale SSH asks for the
  browser check, the console prints the link and a one-line explanation,
  waits up to fifteen minutes for the confirmation, and continues once the
  check is reported as passed.

- The application pre-commit hook lets `.env.example` through. It refused
  every staged `.env.*`, including the example file that the scaffold's own
  `.gitignore` un-ignores on purpose.

Upgrade: pin `v0.31.1`, converge; then `platform update` in each
application repository so the managed hook is rewritten. Nothing changes
on a host beyond the runtime version.

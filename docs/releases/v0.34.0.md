# Platform Automation Core v0.34.0

Grafana shows the whole host, not only one application at a time.

Release assets:

- `otostogan-platform-0.34.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.34.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- A **Host** dashboard beside **Application**: CPU, memory, disk space and
  I/O, network and load of the machine, the containers' CPU and memory split
  by project with the platform as one row, and container restarts per
  project. Every query is pinned to the host chosen at the top. The metrics
  were already collected; nothing new runs on the host.

Upgrade: pin `v0.34.0`, converge. The dashboard appears in Grafana's
Platform folder after convergence. Nothing changes in applications.

# Platform Automation Core v0.26.0

The standard dashboard ranks paths for every application.

Release assets:

- `otostogan-platform-0.26.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.26.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- Three tables on the standard Application dashboard, from the proxy log,
  over the selected time range: the most requested paths, the slowest by
  p95, and those answering 4xx and 5xx. Only the application's own domains
  and only requests that reached it. Nothing is asked of the application.
- Numbers and UUIDs in a path are folded into `:id`, so `/documents/1` and
  `/documents/2` are one address. A guess at the route, not the route.
- The proxy access log carries `path` — the path without the query string —
  beside `request`.

Upgrade: pin `v0.26.0`, converge. The convergence restarts the proxy and
Grafana once. Log lines written before the upgrade have no `path`, so the
tables fill from new requests on.

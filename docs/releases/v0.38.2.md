# v0.38.2

Patch release: a console one patch ahead of its hosts may update an
application.

## Fixed

- `platform update` in an application refused whenever the console was
  newer than the pin of a host it deploys to, a patch release included. A
  console-only fix therefore cost a round of converges that changed nothing
  on the hosts. The check now compares major and minor: a newer minor or
  major still refuses, a patch does not. The reusable workflow an
  application calls stays pinned to the hosts' version.

## Upgrade

- Workstation: reinstall the console wheel from this release.
- Hosts: no runtime change, and no converge is needed for `platform update`
  in applications whose hosts are on any 0.38.x.

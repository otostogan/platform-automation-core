# Platform Automation Core v0.34.1

The host itself is watched: memory and CPU alerts.

Release assets:

- `otostogan-platform-0.34.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.34.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- Two alert rules watch the host: **Host memory low** (free memory below
  `observability_alert_host_memory_free_percent`, 10, for ten minutes) and
  **Host CPU busy** (above `observability_alert_host_cpu_percent`, 90, for
  fifteen minutes). Both name the host and point at the Host dashboard.

Upgrade: pin `v0.34.1`, converge. Nothing changes in applications.

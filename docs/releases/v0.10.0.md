# Platform Automation Core v0.10.0

Runs backups without an operator present, and takes one before every
migration.

Release assets:

- `otostogan-platform-0.10.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.10.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- A deployment now reconciles a systemd timer with what the release declares.
  An application with `backup_enabled: true` gets
  `platform-backup@{project}-{environment}.timer` at its declared
  `interval_minutes`; one that turns backups off, or moves to an external
  database, has its timer disabled and its override removed. Host state that
  outlives the release which created it needs a removal path, and now it has
  one.
- The units are installed by convergence rather than written by a deploy, so
  what runs and as whom is fixed by the operator; a deploy only supplies the
  cadence through a drop-in. `systemd` is reloaded only when that cadence
  actually changes, so a converged host stays quiet.
- Timers carry a randomized delay proportional to the interval, so several
  projects on one host do not dump at the same instant, and `Persistent=true`
  catches up once after downtime rather than once per window missed.
- A timer that cannot be written warns instead of failing the deployment. A
  release already serving traffic is not a failed release.
- A deploy that runs a migration takes a dump first, automatically and
  regardless of the schedule — including when `backup_enabled` is false. That
  flag governs the schedule, and turning it off must not silently remove the
  safety net from a destructive step. **This one does fail the deploy if it
  fails.**
  Retention and scheduling only warn because they tidy up around a release
  that already works; a pre-migration dump is the safety net for a destructive
  step, and if the net cannot be strung the step does not happen.

Not scheduled: applications with an external database, and applications with
`backup_enabled: false`. Both have their timer removed if one existed.

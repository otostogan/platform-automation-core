# Platform Automation Core v0.35.0

A one-off command can take its input.

Release assets:

- `otostogan-platform-0.35.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.35.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `platform exec --stdin` passes the caller's standard input to the
  one-off command, up to 1 MiB, through `compose run -T`; without the flag
  the input stays closed. The console's "Run a script inside the
  application" asks for an input file on the workstation and redirects it
  into ssh. Nothing of the input is written on the host or logged.

Upgrade: pin `v0.35.0`, converge. Applications need no change; `--stdin`
works once the host is converged.

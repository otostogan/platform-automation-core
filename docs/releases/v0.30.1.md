# Platform Automation Core v0.30.1

One-off containers are named as such in metrics and logs.

Release assets:

- `otostogan-platform-0.30.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.30.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- A `compose run` container — a migration, a `platform exec` task — is
  labelled `<service> · one-off` in metrics and logs instead of borrowing
  the service's plain name, so the dashboards no longer show a second `web`
  that lived for seconds. Such a container is never a scrape target for
  application metrics, even when it sits on the edge network.

Upgrade: pin `v0.30.1`, converge. Nothing changes in applications.

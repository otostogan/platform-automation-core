# Platform Automation Core v0.21.1

A restore that was proven now counts as proven, and four console actions
run instead of printing their command.

Release assets:

- `otostogan-platform-0.21.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.21.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- Fix `platform_backup_restore_proven`: the exporter waited for the outcome
  `passed` while `verify-backup` records `succeeded`. The metric stayed 0
  after a proven restore, the dashboard said "not proven" and the
  "Restore is not proven" alert could never clear. Present since v0.20.0.
- Console: `Backups: take one now`, `Backups: prove restorable`,
  `Converge (twice)` and `Readiness` on a host now run; the two backup
  actions are also in an application's menu.
- `platform update` in an infrastructure repository: when every host already
  runs the target version, all hosts start ticked in "Converge which hosts?".

Upgrade: pin `v0.21.1`, converge. A host whose restore was already proven
reports it within a minute of the upgrade, and the alert resolves by itself.

# Platform Automation Core v0.27.0

Images for ARM hosts, and a controller venv that ansible-core can run on.

Release assets:

- `otostogan-platform-0.27.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.27.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- The build workflow takes a list of platforms: `PLATFORMS: linux/amd64` by
  default, `linux/amd64,linux/arm64` for an image a host on ARM can run.
  `platform update` reads the value back, so the edit survives it.
- `platform new company-infra` builds the controller venv on a Python that
  ansible-core 2.15 runs on (3.9–3.11), passing over a newer `python3`;
  `platform doctor` reports the venv's Python and fails on one ansible-core
  cannot use.
- Handbook: the subject of a Tailscale trust credential may come from
  GitHub with numeric ids; the exact one is read off the credential after a
  failed attempt.

Upgrade: pin `v0.27.0`, converge. Then `platform update` in each
application; an application for an ARM host then sets `PLATFORMS` in
`.github/workflows/build.yml` and tags a new version.

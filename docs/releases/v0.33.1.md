# Platform Automation Core v0.33.1

Bucket-only dumps show their time, reason and size in the restore choice.

Release assets:

- `otostogan-platform-0.33.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.33.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `platform backups` lists `offsite_only` entries as `{stamp, bytes}`, the
  size taken from the bucket listing. The console's restore choice shows a
  bucket-only dump in the same columns as the host's own dumps, with "in
  the bucket" where the release would be: the release stays unknown until
  the dump is fetched, since the host can list the bucket but not read a
  card.

Upgrade: pin `v0.33.1`, converge. Nothing changes in applications.

# Platform Automation Core v0.8.1

Installs the age binary. Convergence with `v0.8.0` fails without this.

Release assets:

- `otostogan-platform-0.8.1.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.8.1-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `v0.8.0` fetched and extracted the age archive in one `unarchive` task and
  passed it a `checksum`, which that module does not accept. Every
  convergence failed on it, so `v0.8.0` cannot be converged and should be
  skipped. The archive is now fetched with `get_url`, which verifies the
  checksum, and only then extracted — so nothing is ever unpacked unverified.
- The install runs only when the pinned version is not already present, and
  the archive is removed in an `always` block. A converged host reports no
  change, which is the signal the acceptance sequence depends on.

No runtime or contract changes.

# Platform Automation Core v0.23.0

The console restores a database and rotates its password, and observability
stops counting the internet's noise as the application.

Release assets:

- `otostogan-platform-0.23.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.23.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- Console, in an application's menu: `Database: restore from a dump`. The
  handbook's order, enforced: pick a dump by stamp; prove that very dump if
  it is not proven; take a dump of the current state unless that could push
  the chosen one out of retention, in which case the console says there is
  no way back; type `project/environment`; restore that stamp. A dump taken
  on another release is named before the confirmation, and a host whose
  deployed release cannot be read stops the flow. The console waits two
  hours, longer than the host's own limits.
- Console: `Database: rotate the password`, one confirmation, default no.
- Dashboard: "All" domains means the application's own domains, not every
  `Host` header sent at the proxy.
- Alert "HTTP 5xx rate" counts only requests that reached an application.
  The 503 the proxy's default server gives a scanner no longer counts. An
  application whose containers are gone is seen by "Container down" and
  "Release not running" instead.

Upgrade: pin `v0.23.0`, converge. The console changes need no convergence.

# Platform Automation Core v0.3.2

Fixes a convergence failure in the reboot recovery role.

Release assets:

- `otostogan-platform-0.3.2.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.3.2-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- The reboot recovery role checked the installed entrypoint by passing its
  systemd invocation to `stat`. That invocation is `-m
  platform_automation.reboot_recovery_entrypoint`, a Python module argument
  rather than a path, so the check failed on every host even though the file
  was installed correctly. The module form is required — the entrypoint
  imports its siblings relatively and cannot be run as a bare file — so the
  path to validate is now a separate variable derived from the CLI install
  root.

Nothing else changes. The `platform/v1` contract, server CLI, nginx
activation, rollback, and the SOPS recipient policy are untouched.

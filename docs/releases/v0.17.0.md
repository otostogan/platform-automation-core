# Platform Automation Core v0.17.0

A manifest domain can belong to a helper service and be closed with basic
auth whose password lives only in the environment secrets. The console
rolls back, updates the core host by host, and lists the release history.

Release assets:

- `otostogan-platform-0.17.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.17.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `domains[].service` names the Compose service a domain is for. The web
  service's `PLATFORM_VIRTUAL_HOSTS` / `PLATFORM_TLS_HOSTS` carry only its
  own domains; a helper receives its own through
  `PLATFORM_VIRTUAL_HOSTS_<SERVICE>` / `PLATFORM_TLS_HOSTS_<SERVICE>`. A
  service that is missing or off the `edge` network, or a manifest that
  leaves the web service without a domain, is refused by validation.
- `domains[].auth: {username, password_env}` closes a domain with basic
  auth. At deploy the host reads the value from the release's decrypted
  secrets, writes only its sha512-crypt hash to `htpasswd/<host>` and
  switches nginx in the same transaction as the vhost fragments; the file
  leaves with the domain and comes back with a rollback. The value never
  appears in a message, a log or the ledger.
- `platform status --json` lists `history`: every ledger record summarised,
  newest first.
- Console: «Roll back» (targets chosen by the ledger's rules, migrations
  after the target named, redeploy through GitHub or `rollback --to` on the
  host); `platform update` inside an infrastructure moves the core — pin,
  install, converge twice, readiness — with each host's runtime version
  shown first; «Secrets: push / pull» replace the printed `sops updatekeys`;
  `update` in an application reads the image name from step env and keeps
  the tailnet tag.

Hosts: manifests without the new fields validate and deploy exactly as
before. Converge to pick up the runtime; `domains.py` and `htpasswd.py` are
new host modules. The `htpasswd/` state directory already exists on every
converged host.

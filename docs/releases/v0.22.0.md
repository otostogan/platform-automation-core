# Platform Automation Core v0.22.0

Restores are proven on a calendar, not when someone remembers.

Release assets:

- `otostogan-platform-0.22.0.tar.gz` — Ansible Collection
  `otostogan.platform`.
- `platform_automation_runtime-0.22.0-py3-none-any.whl` — Python runtime and
  controller utilities.
- `SHA256SUMS` — integrity checks for both installable artifacts.

Changes:

- `platform verify-backup --all` restores the newest dump of every
  application that has one and is not retired. One failure does not stop the
  others; the exit code is non-zero if any proof failed. `--all` excludes
  `--project`, `--environment` and `--from`.
- `platform-verify-backups.timer` runs it weekly: Sunday 04:00 UTC by
  default, with up to an hour of random delay, and at the next boot if the
  host was off. `platform_cli_verify_schedule` changes the calendar,
  `platform_cli_verify_enabled: false` turns it off. The run has no overall
  time limit; each step of each proof has its own.

Upgrade: pin `v0.22.0`, converge. The timer is enabled by the convergence.
A failed proof raises "Restore is not proven" on hosts with observability.

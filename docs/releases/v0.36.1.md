# v0.36.1

Patch release: the operator console finds the private key for
`platform secrets pull` itself.

## Fixed

- `platform secrets pull` ran a bare `sops --decrypt`, so it only worked with
  `SOPS_AGE_KEY_FILE` or `keys.txt` set up by hand. The console now offers
  sops, after its own defaults, the host key named by the infrastructure's
  `local-secrets.yml` or key directory, then every recovery key of the
  registered infrastructures, and names the files it tried when none opens
  the ciphertext. An explicit `SOPS_AGE_KEY_FILE` still wins.

## Upgrade

- Workstation: reinstall the console wheel from this release.
- Hosts: no runtime change; converging with the 0.36.1 collection is
  optional.
